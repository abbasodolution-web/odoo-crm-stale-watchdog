Stale Opportunity Watchdog

Never let a deal go quiet. Automatic follow-up reminders for idle CRM opportunities.

Opportunities rarely get lost on purpose — they get forgotten. This module watches your pipeline every day, flags open opportunities that haven't been updated for a number of days you choose, and gives the assigned salesperson a follow-up to-do.

Installation

Install in 3 steps

1
Get the app
Click Download on this page (free).
2
Add it to Odoo
Unzip it into your custom add-ons folder (a folder listed in addons_path) and restart Odoo. On Odoo.sh, push the folder to your repository instead.
3
Install it
Turn on developer mode, open Apps › Update Apps List, search Stale Opportunity Watchdog and click Activate.
How to use

Set it up and use it

1
Set the number of days
CRM › Configuration › Settings › Stale Opportunity Watchdog: how many days without an update make an opportunity stale (default 30).
2
Let it run
A scheduled action checks the pipeline once a day. Stale opportunities get a Stale Opportunity Follow-up activity for their salesperson.
3
Find them
In the pipeline use the Stale Opportunities filter or group by Stale.
4
It clears itself
Update the deal, win it or lose it and the flag goes away.
