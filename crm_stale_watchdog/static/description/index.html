Stale Opportunity Watchdog

Never let a deal go quiet. Automatic follow-up reminders for idle CRM opportunities.

Opportunities rarely get lost on purpose — they get forgotten. This module watches your pipeline every day, flags open opportunities that haven't been updated for a number of days you choose, and gives the assigned salesperson a follow-up to-do.

Key features

  • Configurable threshold — Settings › CRM, default 30 days
  • Daily check — a scheduled action flags idle opportunities automatically
  • Follow-up reminder — a “Stale Opportunity Follow-up” activity for the salesperson
  • No duplicates — never adds a second reminder while one is still open
  • Self-cleaning — the flag clears as soon as the deal is updated, won or lost
  • Pipeline filter — “Stale Opportunities” filter and “Stale” group-by
  • Lightweight — depends only on CRM and Discuss, covered by automated tests

1. Set your threshold

Settings › CRM › Stale Opportunity Watchdog

2. See every stale opportunity

CRM › Pipeline › Filters › Stale Opportunities

3. Salespeople get a follow-up reminder

Shown on the opportunity and in the salesperson's activities
